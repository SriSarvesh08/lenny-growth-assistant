**Current Status:** Milestone 5 (Final Integration, End-to-End Verification & Demo Readiness) — Completed & Verified.

## 🛡️ Secure Artifact Viewer & Security Architecture

1. **Untrusted Model Output:** All model-generated Markdown and HTML are treated as untrusted input.
2. **Strict Sanitization:** Processed through `DOMPurify` with an explicit allowlist of safe formatting tags (`<h1>`–`<h6>`, `<p>`, `<code>`, `<pre>`, `<blockquote>`, `<a>`, `<ul>`, `<li>`, `<table>`).
3. **XSS Defense:** Strips `<script>`, `<object>`, `<embed>`, `<style>`, inline event handlers (`onerror`, `onload`, `onclick`), and dangerous URL schemes (`javascript:`).
4. **Link Hardening:** Automatically enforces `target="_blank"` and `rel="noopener noreferrer"` on all external links.
5. **Dual-Mode Rendering:** Users can view rendered content either via native sanitized DOM or in an isolated sandboxed iframe (`sandbox="allow-same-origin"` with strict Content Security Policy).

## 💻 8 GB RAM Resource Budget

The application is engineered specifically for Windows workstations with 8 GB RAM:
- **Local Ollama Inference:** `llama3.2:3b` loaded in memory (~2.0 GB).
- **PostgreSQL Database:** Docker container capped at 1.0 GB RAM via Compose.
- **FastAPI Backend:** In-process Python ASGI server (~180 MB).
- **Next.js Frontend:** Development server (~250 MB).
- **Headroom:** Preserves ~2.5+ GB free RAM for Windows OS and system processes.

## 🛠️ Step-by-Step Running & Verification Guide

### 1. Start Local Ollama (Mandatory for Local Demo)
Ensure Ollama is running with the required model:
```powershell
ollama run llama3.2:3b
```

### 2. Start PostgreSQL with pgvector (Docker)
From the project root:
```powershell
docker-compose -f docker/docker-compose.yml up -d postgres
```

### 3. Run Backend Server (FastAPI)
In a PowerShell terminal:
```powershell
cd "G:\The Lenny Growth Assistant\backend"
.\venv\Scripts\Activate.ps1
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
The backend API and Swagger docs will be available at:
- **API Health:** `http://localhost:8000/api/health`
- **Interactive Swagger Docs:** `http://localhost:8000/docs`

### 4. Run Frontend Server (Next.js)
In a separate PowerShell terminal:
```powershell
cd "G:\The Lenny Growth Assistant\frontend"
npm run dev
```
Open **`http://localhost:3000`** in your browser.
